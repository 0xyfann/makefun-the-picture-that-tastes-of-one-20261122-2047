A steaming bowl of ramen, drawn from above and rendered entirely in code — no image files, no network, no third-party libraries. `main.py` (Python 3.13, standard library only) paints the picture one pixel row at a time and writes it to `entry.png`: rich amber broth, golden noodle nests, jammy eggs, chashu, nori, spring onion, chilli oil and chopsticks on a walnut table, with steam curling up. One ingredient leads the picture — the broth — and everything else is there to make you taste it.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```

The program writes `entry.png` (1024×1024 PNG, ~306 KB) into `MAKEFUN_OUTPUT_DIR` (or `/output` if unset). It is fully deterministic: two runs produce byte-identical files.
